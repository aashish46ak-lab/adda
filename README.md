# ADDA — Sabai Seller, Eutai Adda

Nepal's multi-vendor marketplace. A digital gathering place for sellers and buyers.

**Tagline:** Seller haru ko digital Adda.

## Stack

- React + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Supabase (Auth, Database, Storage)
- TanStack Query
- Vercel

## Roles

- **Customer** — browse, search, cart, checkout, orders, wishlist, reviews
- **Seller** — shop storefront, products, orders, analytics, earnings
- **Admin** — full platform management, seller approvals, commissions

## Local development

```bash
npm install
npm run dev
```

## Production

Deployed from `main`. Target domain: `shopwithadda.vercel.app`
